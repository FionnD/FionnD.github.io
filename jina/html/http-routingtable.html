HTTP Routing Table

/ | /flows | /peas | /pods | /status | /workspaces
 
/
GET / Home
 
/flows
GET /flows Get all alive Flows' status
GET /flows/arguments Get all accept arguments of a Flow
GET /flows/{id} Get the status of a running Flow
POST /flows Creat a Flow from a YAML config
DELETE /flows/all Terminate all running Flows
DELETE /flows/{id} Terminate a running Flow
 
/peas
GET /peas Get all alive Pea' status
GET /peas/arguments Get all accept arguments of a Pea
GET /peas/{id} Get status of a running Pea
POST /peas Create a Pea
DELETE /peas/all Terminate all running Peas
DELETE /peas/{id} Terminate a running Pea
 
/pods
GET /pods Get all alive Pods' status
GET /pods/arguments Get all accept arguments of a Pod
GET /pods/{id} Get status of a running Pod
POST /pods Create a Pod
DELETE /pods/all Terminate all running Pods
DELETE /pods/{id} Terminate a running Pod
 
/status
GET /status Get the status of the daemon
 
/workspaces
GET /workspaces Get all existing Workspaces' status
GET /workspaces/{id} Get the status of an existing Workspace
POST /workspaces Create a Workspace and upload files to it
DELETE /workspaces/all Deleting all Workspaces
DELETE /workspaces/{id} Deleting an existing Workspace
